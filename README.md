# NovaFisio Picos — Home v1

Primeira versão da Home em HTML5, CSS3 e JavaScript vanilla, com abordagem mobile first.

## Arquivos
- index.html
- assets/css/style.css
- assets/js/main.js
- assets/images/favicon.svg
- robots.txt
- sitemap.xml

## Conteúdo que ainda precisa ser substituído/confirmado
1. Fotografias reais da clínica: hero, ambientes, fachada, recepção, consultórios e equipamentos.
2. Fotografias e dados reais dos profissionais: nome, especialidade, registro e perfil.
3. Avaliações/depoimentos reais.
4. Logotipo oficial, quando fornecido.
5. Confirmar o domínio definitivo antes da publicação para canonical, sitemap e robots.
6. Confirmar o link exato do Perfil da Empresa no Google/Google Maps para os botões e avaliações.

Os placeholders foram mantidos de forma explícita para não apresentar imagens, profissionais ou depoimentos fictícios como reais.
